# SLG · Soluciones Logísticas Globales

Sitio web corporativo de **Transportes SLG** — transporte terrestre y logística de carga contenerizada, con cobertura nacional en México.

## Estructura

- `index.html` — Página principal (one-page): hero, nosotros, servicios, cobertura, beneficios, proceso, testimonios, galería, FAQ y contacto.
- `aviso-privacidad.html` — Aviso de Privacidad Integral (LFPDPPP) y Términos de uso.
- `assets/` — Logotipo e imágenes optimizadas de la flota.
- `vercel.json` — Configuración de despliegue (URLs limpias y caché de imágenes).

## Tecnología

Sitio 100% estático: HTML, CSS y JavaScript sin dependencias ni build. Diseño responsive con modo claro/oscuro.

## Despliegue

Optimizado para [Vercel](https://vercel.com). Al ser estático, no requiere paso de compilación.
